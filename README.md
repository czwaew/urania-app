# 星しずく占い Ver3.0

GitHub Pagesで動作する静的Webアプリです。

## 搭載機能
- AI占い風チャット（端末内処理）
- 78枚タロット、正逆位置、1枚・3枚・ケルト十字
- 12星座占い
- 簡易姓名判断
- 生年月日・数秘術
- 端末内ログイン
- ポイント・毎日ログインボーナス
- 占い履歴
- 広告差し替え枠
- 星・カードアニメーション
- PWA、オフライン対応

## GitHub Pagesへの公開
このフォルダ内のファイルをリポジトリ直下へアップロードし、Settings → Pages → Deploy from a branch → main / root を選択します。

## 本物のAIチャットへ接続する場合
OpenAI APIキーを `app.js` や `index.html` に直接書かないでください。第三者に閲覧されます。
サーバー側にAPIキーを保存し、アプリから自分のサーバーAPIを呼び出す構成にしてください。

## ログインについて
現在のログインはデモ用で、入力内容は利用者の端末内（localStorage）だけに保存されます。
Googleログインや本格会員機能にはFirebase Authentication等が必要です。

## 広告について
画面下部の広告枠を、Google AdSense審査通過後に発行される広告コードへ差し替えてください。
