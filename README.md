# 星しずく占い Ver2.0

GitHub Pagesへ上書きして使える総合占いWebアプリです。

## 体験版で実際に動く機能
- AI占い風チャット（端末内ロジック・会話履歴保存）
- 78枚タロット、正逆位置、1枚・3枚・ケルト十字、カード図鑑
- 12星座の今日・週間・月間占い
- 数秘術、九星気学の簡易診断、誕生日性格診断
- 簡易五格姓名判断、恋愛・結婚・友達相性
- カード反転、星空、パーティクル、効果音、ダーク/ライト
- デモGoogle/Appleログイン、プロフィール、お気に入り、履歴、ランキング
- ログインボーナス、ポイント、ミッション、バッジ、チケット
- プレミアム・追加購入のデモ画面、広告枠
- PWA、オフライン、iPhoneホーム画面追加、Android PWA対応

## 本番接続が必要な機能
Google/Appleログイン、OpenAI API、Stripe決済、AdSense/AdMobは、各サービスの審査・登録・バックエンド・秘密鍵が必要です。GitHub Pagesだけでは秘密鍵を安全に保持できません。`server-example` は接続用の見本です。

### 安全上の重要事項
- OpenAIやStripeの秘密鍵を `app.js` やGitHubへ書かないでください。
- APIリクエストと決済は必ず自分のバックエンドを経由します。
- Google/Appleログインは取得したIDトークンをバックエンドで検証してください。
- 姓名判断・九星気学は現在、娯楽向け簡易計算です。正式サービス化には監修を推奨します。
- AdMobはネイティブAndroid/iOSアプリ向けです。Web/PWAではAdSenseを使用します。

## GitHub Pages公開
このフォルダ直下の `index.html` などをリポジトリのルートへ上書きし、Settings → Pages → main / (root) を保存してください。
