# 星しずく占い＋ Ver4.0 Ultimate

## GitHub Pagesで動作する機能
- AI占い体験版チャット
- 恋愛・仕事・人生相談
- 78枚タロット、正位置・逆位置
- 1枚引き、3枚引き、ケルト十字
- 星座占い、姓名判断、数秘術、九星気学、誕生日占い、相性診断
- 端末内ログイン画面
- ポイント、毎日ログインボーナス
- 占い履歴、お気に入り、実績バッジ
- 広告枠、プレミアム体験版
- 星空・カードアニメーション
- PWA、オフライン対応
- Androidインストール、iPhoneホーム画面追加対応

## GitHubへのアップロード
`uranai-app-v4-ultimate` フォルダ内のファイルを、リポジトリ直下へすべてアップロードしてください。
`server-example` フォルダはGitHub Pages上では動きませんが、本物のOpenAI API接続時に使用します。

## 本番接続が必要な機能
次の機能は各サービスの契約・審査・設定が必要です。
- OpenAI API
- Googleログイン
- Appleログイン
- Google AdSense / AdMob
- Stripe決済

APIキーやStripe秘密鍵をHTMLやapp.jsへ直接書かないでください。必ずサーバー側の環境変数へ保存してください。

## 注意
姓名判断と九星気学は簡易判定版です。正式鑑定には画数辞典、旧字体対応、立春基準の専門暦データなどが必要です。
